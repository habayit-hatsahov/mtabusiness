# גרסת אייפון 1.0.1 – מה עושים על המק (לאבירן)

**כמה זמן:** כ-20 דקות, ועוד כמה דקות של העלאה שרצה לבד.
**מה צריך:** המק עם Xcode, האייפון שלך, וכבל.
**כל מה שבגרסה כבר מוכן ונמצא בגיט** – לא כותבים קוד, רק מושכים, בודקים ומעלים.

**מה חדש בגרסה (בשביל הבדיקה בשלב 3):**
- מסך פתיחה חדש: **הלוגו המלא של Yellow Zone** על צהוב (במקום ה-Z בלבד).
- שורת השעה נשארת לבנה כשגוללים, והשעה קריאה גם במצב כהה.
- השם "Yellow Zone" (ולא "App") בחלון הכניסה של Google.
- קישור `yellowzone.co.il/download` פותח את האפליקציה ישירות.

---

## שלב 1 – למשוך ולהכין (מסוף / Terminal)

להעתיק את כל הבלוק ולהדביק בבת אחת:

```bash
cd ~/mtabusiness && git pull && cd app && npm install && npx cap sync ios && open ios/App/App.xcodeproj
```

> אם התיקייה אצלך בשם אחר – להחליף את `~/mtabusiness` בנתיב שלך.
> `npx cap sync ios` **חובה** – בלעדיו האפליקציה לא יודעת לאיזה אתר להתחבר (דף לבן).

## שלב 2 – לוודא את ההרשאות (Xcode)

בצד שמאל: **App** ← לשונית **Signing & Capabilities**. צריכים להופיע:
- **Sign in with Apple**
- **Associated Domains** עם `applinks:yellowzone.co.il`

אם יש הודעת שגיאה אדומה על provisioning – ללחוץ **Try Again**.

## שלב 3 – להריץ על האייפון ולבדוק (לפני ההעלאה!)

לחבר את האייפון בכבל, לבחור אותו למעלה ברשימת המכשירים, וללחוץ ▶ (Run).

| # | מה בודקים | מה אמור לקרות |
|---|---|---|
| 1 | פותחים את האפליקציה | מסך צהוב עם **הלוגו המלא** (לא Z) |
| 2 | המעבר מהמסך הראשון למסך הצהוב של האתר | הלוגו **לא קופץ** – אותו גודל ואותו מקום |
| 3 | גלילה בדף הבית | האזור של השעה נשאר **לבן** |
| 4 | מצב כהה בטלפון | השעה עדיין **כהה וקריאה** |
| 5 | כניסה עם Google | החלון כתוב **Yellow Zone** |
| 6 | לשלוח לעצמך ב-Notes את `https://yellowzone.co.il/download` וללחוץ | **האפליקציה נפתחת** (אם Safari נפתח: לחיצה ארוכה ← "פתח ב-Yellow Zone") |
| 7 | פתיחת כרטיס עסק | נפתח רגיל |

⚠️ **אם בבדיקה 1 עדיין רואים Z:** האייפון שומר את מסך הפתיחה הישן. למחוק את האפליקציה מהטלפון ולהריץ שוב (▶). אם עדיין – להפעיל את הטלפון מחדש.

📸 **לצלם לרמי סרטון מסך קצר של הפתיחה** (בדיקות 1–2) – זה מה שהוא ביקש לתקן.

**אם משהו לא תקין – לעצור כאן ולשלוח לרמי צילום.** לא להעלות.

## שלב 4 – להעלות לאפל

1. למעלה ברשימת המכשירים: **Any iOS Device (arm64)**
2. תפריט **Product ← Archive** (כמה דקות)
3. בחלון שנפתח: **Distribute App ← App Store Connect ← Upload** – ו-Next עד הסוף

הגרסה כבר מוגדרת: **1.0.1, Build 3**. אם אפל עונה ש-Build 3 כבר קיים: **App ← General ← Build** → 4, ושוב Archive.
