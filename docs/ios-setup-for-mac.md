# הקמת גרסת האייפון — מדריך צעד אחר צעד

**למי זה מיועד:** מי שעושה את זה על המק. לא צריך רקע טכני — כל מה שצריך זה להעתיק
שורות ולהדביק, וללחוץ על כמה כפתורים.

**מה אנחנו עושים בגדול:** לאפליקציה כבר יש גרסת אנדרואיד שעובדת ונמצאת בחנות.
עכשיו מייצרים ממנה גם גרסת אייפון. **לא כותבים שום קוד** — יש פקודה שמייצרת את זה לבד.

**כמה זמן:** ההורדות לוקחות שעתיים-שלוש (רצות לבד ברקע). העבודה בפועל — בערך חצי שעה.

## ⚠️ לפני הכל — דבר אחד שחשוב לדעת מראש

בשלב 5 מתחברים לחשבון של רמי באפל, והוא ימסור לך את פרטי הכניסה.

*(למה בחשבון שלו ולא בשלך: חשבון מפתח של אדם פרטי אצל אפל **לא מאפשר להוסיף אנשים
נוספים** לצוות. זו מגבלה של אפל, אין דרך לעקוף אותה.)*

🔴 **ומה שחשוב באמת — סיסמה לבדה לא תספיק.** לחשבון יש אימות דו-שלבי: ברגע שתלחץ
"התחבר", אפל תשלח **קוד בן 6 ספרות לטלפון של רמי**. בלי הקוד הזה אי אפשר להיכנס,
והוא תקף לדקות ספורות.

👉 **המסקנה המעשית:** לפני שאתה מתחיל את שלב 5, **תוודא שרמי זמין בטלפון באותו רגע.**
שלבים 1–4 אפשר לעשות לבד לגמרי ובנחת.

## שלב 1 — Xcode *(התחל מזה, זו ההורדה הארוכה)*

Xcode היא התוכנה של אפל לבניית אפליקציות.

1. פותחים את **App Store** במק
2. מחפשים **Xcode**
3. לוחצים **Get** / **התקן**

📦 זו הורדה של בערך **15 ג'יגה**. לוקחת בין שעה לשלוש.
**אפשר להשאיר אותה רצה ולהמשיך לשלב 2 במקביל.**

✅ **איך יודעים שסיימת:** Xcode מופיעה ברשימת התוכנות ונפתחת.
בפתיחה הראשונה היא תבקש אישור ותתקין עוד כמה רכיבים — מאשרים ומחכים.

## שלב 2 — Node

זו תוכנת עזר שהפקודות בשלב 4 צריכות.

1. נכנסים ל־**nodejs.org**

✅ **איך יודעים שהצליח:** בשלב 4 הפקודות פשוט יעבדו. אם לא — כתוב שם מה לעשות.

4. **שולחים לרמי את שם המשתמש שלך ב-GitHub**, והוא מזמין אותך לפרויקט

## שלב 4 — חמש פקודות

**איך פותחים את Terminal:** לוחצים `Command` + `רווח`, כותבים `Terminal`, ו־Enter.
נפתח חלון לבן או שחור עם טקסט. זה המקום.

**איך עובדים:** מעתיקים שורה אחת, מדביקים, לוחצים Enter, **ומחכים** עד שהסמן חוזר
ואפשר להקליד שוב. רק אז עוברים לשורה הבאה.

> ℹ️ **הרבה טקסט שרץ על המסך זה תקין ותקין לגמרי.** זה לא שגיאה — ככה זה נראה.

```
cd ~/Documents/GitHub/mtabusiness/app
```

```
npm install
```

```
npm install @capacitor/ios @capawesome/capacitor-apple-sign-in
```

```
npx cap add ios
```

```
npx cap open ios
```

✅ **איך יודעים שהצליח:** אחרי הפקודה האחרונה **Xcode נפתחת לבד** עם הפרויקט.
זה הסימן שכל השלב עבד.

## שלב 5 — התחברות לחשבון *(כאן צריך שרמי יהיה זמין בטלפון)*

בתוך Xcode:

1. בסרגל העליון: **Xcode → Settings** *(או Preferences בגרסאות ישנות)*
2. לשונית **Accounts**
3. כפתור **+** בפינה השמאלית התחתונה → **Apple ID**
4. מזינים את פרטי הכניסה שרמי מסר
5. 📞 **אפל תבקש קוד בן 6 ספרות** — מתקשרים לרמי, הוא מקריא, מקלידים

> 🔴 **אם נפתחת שאלה על iCloud** *(תמונות, אנשי קשר, מסמכים, "Find My")* —
> **תסמן שלא לכל האפשרויות.** אנחנו צריכים רק את ההרשאה לבנות אפליקציה, ואין שום
> סיבה שהתמונות ואנשי הקשר של רמי ירדו למחשב שלך.

✅ **איך יודעים שהצליח:** ברשימה מופיע `Rahamim Tal` עם המספר `MX427CFSV2`.

> ℹ️ **כשמסיימים הכל** — אפשר לחזור ל-**Xcode → Settings → Accounts**, לבחור את החשבון
> וללחוץ **–** כדי להתנתק. הפרויקט שכבר נבנה לא נפגע מזה.

## שלב 6 — שתי הגדרות ב-Xcode

*(אחרי ששלב 5 הצליח, אפשר להמשיך לבד)*

1. בעמודה השמאלית של Xcode — לוחצים על **השורה העליונה ביותר**, זו עם האייקון הכחול
   (כתוב עליה **App**)
2. באמצע המסך נפתחות לשוניות — בוחרים **Signing & Capabilities**
3. מוודאים ש**וי** מסומן ליד **Automatically manage signing**
4. בשדה **Team** בוחרים מהרשימה את **Rahamim Tal**

   ✅ שורת האזהרה האדומה שהייתה שם אמורה להיעלם. אם היא נשארה — צילום מסך, עוצרים.

5. עכשיו מוסיפים יכולת: לוחצים **+ Capability** *(בפינה השמאלית העליונה של אותו אזור)*
6. נפתח חלון חיפוש — כותבים **Apple** ובוחרים **Sign in with Apple**, לחיצה כפולה

   ✅ אמור להופיע קופסה חדשה בשם **Sign in with Apple** ברשימה שמתחת.

## 🆘 אם נתקעת

**הכלל:** אם מופיע טקסט אדום עם המילה `error` — **עצור, אל תנסה שוב, תצלם מסך ותשלח.**
ניסיון חוזר בדרך כלל לא עוזר, ולפעמים מסבך.

### התקלה הכי נפוצה — משהו על `pod` או `CocoaPods`

אם בשלב 4 מופיעה שגיאה שמזכירה `pod` או `CocoaPods`, מריצים את שתי הפקודות האלה
(אחת אחרי השנייה, ומחכים):

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

```
brew install cocoapods
```

ואז חוזרים ומריצים שוב את `npx cap add ios` משלב 4.

> ℹ️ ההתקנה הראשונה תבקש את סיסמת המשתמש של המק שלך — זו הסיסמה שלך, וזה תקין.
> בזמן ההקלדה לא יופיעו כוכביות. זה תקין גם כן.

### דברים שהם **לא** תקלה

| מה שרואים | האם זה תקין |
|---|---|
| מאות שורות טקסט רצות | ✅ תקין |
| המילה `warning` בצהוב | ✅ תקין, מתעלמים |
| `npm install` לוקח כמה דקות | ✅ תקין |
| טקסט **אדום** עם `error` | ❌ עוצרים ומצלמים |

## למי שכן רוצה לדעת מה קרה כאן

`npx cap add ios` לוקח את האתר הקיים ועוטף אותו בפרויקט אייפון אמיתי — בדיוק כמו
שכבר נעשה לאנדרואיד. התוסף שמותקן בשורה שלפניה מוסיף את היכולת של "התחברות עם Apple",
שאפל **מחייבת** בכל אפליקציה שמציעה התחברות דרך שירות אחר.

**הצד התוכנתי כבר מוכן ומחכה** — השרת יודע לאמת את ההתחברות הזאת, ויש מודול שכתוב
ונבדק (`native-apple.js`). מה שחסר זה רק פרויקט האייפון עצמו, וזה מה שהמדריך הזה מייצר.
