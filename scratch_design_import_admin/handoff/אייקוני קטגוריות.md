## שני סוגי אייקונים — הבדל שחשוב לממש נכון

**1. אייקונים חד־צבעוניים** (כל השאר) — סילואטה שטוחה, קיימים בשלוש גרסאות:
`NAME-navy.png` · `NAME-yellow.png` · `NAME-white.png`
בוחרים את הגרסה לפי צבע האריח.

**2. אייקונים בצבעי המותג** — `zmark-full.png` ו־`emblem-full.png`.
קובץ אחד בלבד, **לא נצבע מחדש**: הוא מכיל כחול `#0A2A66`, לבן, ובמקרה של ה־Z גם צהוב `#FFD400`.

שני האייקונים האלה מכילים לבן, ולכן קריאים גם על אריח כחול — אבל בבחירת אריח כהה כדאי לזכור שהקווים הכחולים שבתוכם נבלעים בו.

## מימוש

```js
const CATEGORY_ICONS = {
  all:     { file: 'zmark-full.png',      tile: '#ffffff', border: '1px solid #E7E7E0' },
  liked:   { file: 'emblem-full.png',     tile: '#FFD400' },
  food:    { file: 'hotdog-yellow.png',   tile: '#0A2A66' },
  events:  { file: 'drum-navy.png',       tile: '#FFD400' },
  vehicle: { file: 'fanbus-yellow.png',   tile: '#0A2A66' },
  home:    { file: 'seat-navy.png',       tile: '#FFD400' },
  fashion: { file: 'bucket-yellow.png',   tile: '#0A2A66' },
  sport:   { file: 'ball-navy.png',       tile: '#FFD400' },
  digital: { file: 'wreath-yellow.png',   tile: '#0A2A66' },
  finance: { file: 'flare2-flat-navy.png',tile: '#FFD400' },
};
```

האייקון ממורכז באריח עם padding של כ־20% מגובה האריח, `object-fit: contain`.
פינות האריח מעוגלות — 14px באריח 52px, 22px באריח 72px.

## הערות

- **מקור האייקונים:** `art/color/`. יש להעתיק את התיקייה לפרויקט.
- כל האייקונים באותה שפה ויזואלית — תרבות אוהדים (כדור, תוף, מגאפון, זר, אבוקה, אוטובוס אוהדים).
- `zmark-full` ו־`emblem-full` נגזרו מקבצי המותג המקוריים ושומרים על הצבעים שלהם.
- **הלוגו המלא (YellowZone) לא נכנס לסט** — יחס 4.26:1 לא עובד באריח ריבועי; ה־Z הוא הגרסה הריבועית שלו.
