## 3. אזור: דשבורד ראשי (Home)

**סרגל KPI:** משימות פתוחות (ממתינים+שינויים) · זמן טיפול ממוצע (registeredAt→approvedAt אמיתי) · עסקים פעילים/רשומים · אוהדים רשומים +X השבוע
*הוסר בכוונה: "כניסות ב-24 שעות" — אין מעקב session במערכת*

**מרכז המשימות** — 4 לשוניות עם מונים, כל אחת Master-Detail (רשימה + כרטיס מלא פתוח מיד, ללא "פתח כרטיס"):
| לשונית | מי נכנס | מיון ברירת מחדל |
|---|---|---|
| אוהדים ממתינים | members status=pending | החדשים / הוותיקים / טרם נבדק קודם / נבדק קודם |
| עסקים חדשים | businesses status=pending | **הכי פחות שלבים נסקרו** |
| עסקים לטיפול | `bizHasAnyPendingChange` | החדשים / הוותיקים + סינון סוג |
| 💯 בריאות פרופיל | approved עם healthScore<70 | הכי פחות בריא |

סינון סוג ב"עסקים לטיפול": הכל / שינוי פרטים / תגית / קטגוריה / כתבו לנו

**פאנל roadmap** בתחתית — מה טרם נבנה.

## 4. אזור: כל העסקים

סינון: סטטוס · קטגוריה · מיון (חדש/ותיק/קליקים/לייקים/שלבים נסקרו ↑↓) · חיפוש (שם/עיר/קטגוריה)
"⚙️ עוד סינונים" (מקופל): סוג עסק · מצב סקירה (<4/4 או 4/4) · בריאות פרופיל (<100%/100%) · טווח תאריכים (7/30/90)
בחירה מרובה → בולק: אשר / דחה / שלח הודעה לנבחרים

**שורת עסק:** צ'קבוקס · שם · תג "✏️ שינויים" / "🏷️ בקשה ממתינה" / "💬 כתבו לנו" · 🔗 דשבורד · 📲 · ✉️ · באדג' n/4 נסקר · ✓מנוי/לא מנוי · שם בעל העסק · "ממתין לפני X" · צ'יפ סטטוס

### כרטיס העסק — 5 שלבים, כל שלב תצוגה+עריכה משלו
כותרת: שם · 🔗 דשבורד · 🔑 קוד כניסה (נשלף מ-members) · 📲 · ✉️ · n/4 נסקר · 📜 תקנון · סטטוס מייל
פעולות: אשר / דחה (pending) · אשר שינויים / ערוך שינויים / דחה שינויים · 🗑️ מחק
מעל השלבים: 📝 תקציר "מה מבקשים לשנות (N)" — כל שורה קופצת לשלב הרלוונטי + הבהוב · 💬 תיבת "כתבו לנו" · 📧 היסטוריית מיילים · 🚩 סימונים · 🗂️ סימוני סקשן (רק approved)

| שלב | תוכן | נסקר? |
|---|---|---|
| 1 — בעל העסק | שם/טלפון/מייל + אקורדיון אימות מנוי (שער+מס' מנוי, או פייסבוק+תמונת הוכחה) | לא במעקב (אין שיקול דעת) |
| 2 — פרטי העסק | סוג עסק (3 צ'קבוקסים חושפים שדות), תיאור, סניפים, אתר אונליין, אזורי פעילות, יצירת קשר, שעות, נוכחות דיגיטלית | ✓ |
| 3 — קטגוריה ותגיות | קטגוריה ראשית + "מופיע גם תחת" + תגית ראשית/שנייה מהפול הנעול | ✓ |
| 4 — הטבה | הטבה 1 מלאה + מקום מימוש + 🤖 כותרת AI (מדידת פיקסלים אמיתית מול רוחב כרטיס 141px, "הצע 3 כותרות") + הטבות 2-3 | ✓ |
| 5 — מדיה | לוגו · תמונה מייצגת · גלריה · סרטונים — העלאה/הסרה נשמרת מיד | ✓ |

**בריאות פרופיל** = 4 בדיקות: תמונה מייצגת · שעות · תיאור · הטבה מוגדרת
**סקירה** = סימון ידני של מנהל לשלבים 2-5. אישור עם <4/4 מציג תזכורת רכה, לא חוסם.

## 5. אזור: כל האוהדים

סינון: סטטוס · טווח תאריכים · מיון (חדש/ותיק/טרם נבדק/נבדק) · חיפוש (שם/טלפון/מייל). בולק: אשר/דחה/הודעה.
**שורה:** שם · 📲 ✉️ · ✓נבדק / ⏳טרם נבדק · ✓מנוי/לא מנוי · 🏪 שם העסק המקושר · 📝 (יש הערה) · "ממתין לפני X"
**כרטיס:** 🔑 קוד כניסה · 🏪 דשבורד העסק המקושר · סטטוס מייל · דגל `name_mismatch` · 🔍 בדיקת מנהל (צ'קבוקס + הערה פרטית) · פרטי קשר ואימות מנוי (תצוגה/עריכה) · תמונת הוכחה · בעל עסק

**אישור אוהד** = הקצאת `memberNumber` (transaction על counters) + `loginCode` 6 ספרות ייחודי + `loginCodeEmailStatus:'pending'` → מייל אוטומטי (Brevo)
**אישור עסק** = status:approved + `approveLinkedMember` (מאשר את החבר, מקצה מספר+קוד אם אין, `isBusinessOwner:true`)
**דחייה** של מאושר = חזרה ל-pending. דחייה של pending = rejected.

## 8. אזור: סקשנים וקטגוריות (עיגונים)

5 סקשנים: ⭐ נבחרים · ✨ חדש אצלנו · 💛 הטבות שוות · 🛒 קניה אונליין · 🏬 כל העסקים — ועוד 8 קטגוריות. לכל אחד **10 מיקומים**.
מיקום פנוי = סבב יומי הוגן אוטומטי. מיקום מעוגן = עסק קבוע שם.
כשירות: featured/new — כל עסק מאושר (הדגל ידני של מנהל). deals — רק עם הטבה. online — רק שסימנו אונליין. קטגוריה — רק עסקים ששייכים לה.

לכל עיגון: **קבוע** (♾ עד הסרה) או **זמני** (N ימים → פוקע). לשניהם אפשר להגדיר **מחליף מתוכנן** — בזמני נכנס אוטומטית בפקיעה, בקבוע בתאריך שבוחרים ("בעוד 45 יום"). המחליף עצמו יכול להיות קבוע או זמני.
**פאנל "מה מסתיים/מתחלף בקרוב"**: מקובץ ל-⚠️ ללא מחליף (יחזרו לאוטומטי) / ✓ יש מחליף. באדג' דחיפות: ≤3 ימים אדום, ≤7 כתום.
**תצוגה מקדימה** של 10 המיקומים כמו שייראו בפועל (📌 מעוגן / סבב אוטומטי).

**סימוני סקשן בכרטיס העסק:** ✨ חדש (N ימים) · ⭐ נבחר (קבוע/זמני) · 💛 הטבות שוות (toggle) · 💙 לב מוצג (override מספר לייקים + תפוגה)

## 10. תהליכים מרכזיים (end-to-end)

**הרשמת אוהד** → members pending → מסך "הבקשה התקבלה" → מנהל בודק (תמונת הוכחה / מנוי / דגל דדופ) → סימון "נבדק" + הערה → אשר → memberNumber + loginCode → מייל קוד כניסה

**הרשמת עסק** (5 שלבים בטופס) → businesses pending → מנהל עובר שלב-שלב ומסמן "נסקר" (2-5) → תיקונים ישירות בכרטיס → אשר → approveLinkedMember → מייל אישור עם לינק דשבורד אישי → מנהל מסמן סקשנים/מעגן במיקומים

**בקשת שינוי מבעל העסק** (מהדשבורד שלו) → `pendingChanges` → עסק נכנס ל"עסקים לטיפול" → תקציר בראש הכרטיס + צביעת השלב + השדה + "🔸 היה: X" → אפשר לערוך את הערך שהעסק ביקש לפני האישור → אשר שינויים (כותב ומנקה) / דחה

**בקשת תגית** → תגית שנייה מהפול, או הצעה חופשית → תור ניהול תגיות → אישור כחדשה (עם בחירת קטגוריה) / מיפוי לקיימת / דחייה

**"רוצה לכתוב לנו משהו?"** → `note` → תיבה בולטת בכרטיס → "סמן כטופל" → מתכווץ ל-details
