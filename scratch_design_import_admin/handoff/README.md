## שלושה דברים שאסור לפספס

**1. הצבע לא מסמן דחיפות.**
כחול = סיווג · צהוב = פעולה ראשית · כתום = חסר או לא אומת. אין אדום בסיווג.

**2. כל מונה נגזר ממקור אחד.**
אסור להקליד את אותו מספר בשני מקומות. זה הכשל שחזר הכי הרבה פעמים בעיצוב.

**3. אישור ודחייה הם פר־בקשה.**
`approveChangeField(bizId, field, valueOverride)`. "אישור כל הבקשות" הוסר במכוון.
