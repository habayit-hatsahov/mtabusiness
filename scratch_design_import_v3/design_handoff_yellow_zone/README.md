# Handoff: Yellow Zone — עיצוב מחדש (פיד הטבות)

## Overview
עיצוב מחדש של Yellow Zone — פלטפורמת ההטבות לאוהדי מכבי. החבילה מכסה את מסך הפיד (דסקטופ + מובייל), הבאנרים העליונים, כרטיס העסק וכרטיס פתוח (מודאל), הדר, פוטר ומצבי טעינה (skeleton).

## About the Design Files
הקבצים בחבילה הם **קובצי עיצוב (design references) שנכתבו ב-HTML** — פרוטוטייפים שמראים מראה והתנהגות מכוונים, **לא קוד פרודקשן להעתקה ישירה**. המשימה היא **לשחזר את העיצובים האלה בקוד הקיים של האתר** (React/Vue/וכו') לפי הדפוסים, הקומפוננטות וספריות ה-UI שכבר קיימים שם. אם אין עדיין סביבה — לבחור את הפריימוורק המתאים ולממש בו.

הערה טכנית: הקבצים הם `.dc.html` — HTML רגיל עם משתני CSS מוגדרים בבלוק `<style>` בראש הקובץ. אפשר לפתוח אותם בדפדפן. מאפיינים כמו `style-hover="..."` הם קיצור של הכלי שבו נבנה העיצוב — בקוד אמיתי הם פשוט `:hover`. ביטויים בסגנון `{{ ... }}` הם חיבורי state (לייק / גלילה) — ראו סעיף State.

## Fidelity
**High-fidelity.** צבעים, טיפוגרפיה, מרווחים, רדיוסים וצללים סופיים. יש לשחזר פיקסל-פרפקט, אך באמצעות הקומפוננטות והספריות הקיימות בקוד. תמונות העסקים הן **גרדיאנטים ממלאי־מקום** — יוחלפו בצילומים אמיתיים (`object-fit: cover`, יחס 4:3).

## Direction (חשוב לשמור)
- **דו-גוני בלבד: צהוב + כחול.** אין גוון שלישי בממשק. הצהוב `#FFD400` הוא צבע הפעולה (כפתורים, קווים מפרידים, אריח קטגוריה פעיל); הכחול `#0A2A66` הוא הדיו, הקווים והמסגור.
- RTL בכל המסמך (`dir="rtl"`).
- ההדר והפוטר לבנים, וכל אחד מהם ממוסגר ב**שני פסים 3px** — צהוב ואז כחול (בהדר מתחת לשורה, בפוטר מעליה).
- כותרות מקבלות "אנדרליין" קצר: 44×3px צהוב מתחת לכותרת הסקשן (במובייל 38×3px).

## Interactions & Behavior
- **לייק**: לחיצה על העיגול מחליפה `fill` בין `none` ל-`#0A2A66`. אין ניווט (stopPropagation מהכרטיס).
- **כרטיס**: לחיצה פותחת את המודאל של העסק.
- **חיצי שורה**: גוללים את שורת הכרטיסים ב-~260px (`scrollBy`, `behavior:'smooth'`).
- **גלילה**: שורות הכרטיסים והקטגוריות נגללות אופקית; פס הגלילה מוסתר.
- **Hover**: כרטיס — הרמה + הגדלת תמונה (ערכים למעלה); כפתורים ואריחים — רקע `#F2F2EC`.
- **Focus**: יש להוסיף `:focus-visible { outline:2px solid #0A2A66; outline-offset:2px }` לכל אלמנט אינטראקטיבי (לא מומחש בפרוטוטייפ).
- **רספונסיביות**: דסקטופ ~2 כרטיסים גלויים ברוחב הקונטיינר (1180px), מובייל 1.5 כרטיסים (כרטיס 216px ברוחב מסך 390px).

## State Management
- `favorites: Record<businessId, boolean>` — מצב הלב לכל כרטיס.
- `openBusinessId: string | null` — איזה עסק פתוח במודאל.
- `activeCategory: string` — הקטגוריה הנבחרת (ברירת מחדל "הכל").
- `searchQuery: string`.
- `isLoading` לכל סקשן — מציג skeletons באותה גיאומטריה.
- שליפת נתונים: רשימת עסקים לפי קטגוריה/חיפוש, "חדש אצלנו", ובאנרים (עסק השבוע / הטבת השבוע / הצטרפו השבוע).

- **אין ירוק בשום מקום.** גם כפתור WhatsApp הוא כחול `#0A2A66` עם טקסט לבן.
- **אין קווים מפרידים בתוך כרטיס העסק הפתוח** — ההפרדה במרווחים בלבד.

- הפוטר: **פס צהוב 3px, פס כחול 3px, ואז שורה לבנה** `padding:10px 28px` (מובייל `8px 16px`) — רק לוגו + "אינסטגרם" + "תנאי שימוש".
